Source, levels and file details

All candidates were synthesized specifically for this project with noise, oscillators and envelopes. There are no third-party recordings, samples, soundfonts or attribution requirements.

Files are mono, 44.1 kHz, 16-bit PCM WAV. Single shots target −24 dBFS RMS with a −9 dBFS peak ceiling. The ceiling prevents some sounds from reaching the RMS target. This is signal-level matching, not a guarantee of equal perceived loudness. Demos retain the single-shot gain unless overlap requires attenuation.
